# CampusQueue

Smart Queue and Appointment Management System for Colleges.

## Features
- Student, staff and admin dashboards
- Online appointment booking
- Digital queue token generation
- Real-time queue tracking
- Estimated waiting time
- Queue analytics

## Technology Stack
- HTML, CSS, JavaScript
- Bootstrap
- Node.js and Express.js
- Supabase PostgreSQL
- Supabase Auth
- Socket.IO
- Chart.js
